# 당일 대체 스케줄 배정 시스템 v24

`index.html`을 브라우저에서 열어 사용합니다. SheetJS Community Edition 0.18.5를 HTML에 포함했으므로 별도 설치·서버·인터넷 연결 없이 XLSX 읽기와 결과 다운로드가 가능합니다. SheetJS 라이선스는 `SheetJS-LICENSE.txt`에 있습니다.

1. 일일 XLSX 파일을 업로드합니다. 첫 번째 시트의 3행부터 읽습니다.
2. 연차 치료사를 선택하고 종일 또는 시간 연차를 설정합니다.
3. 자동 배정을 실행하고 미배정 사유를 확인합니다.
4. 엑셀 내보내기로 배정 결과·미배정·업데이트 스케줄의 3개 시트가 포함된 새 파일을 다운로드합니다.

입력 형식은 인수인계서 기준입니다. F열은 치료사 이름, G열은 숫자 건수이며 H열(8:00)부터 3열마다 30분 슬롯입니다. 슬롯 셀은 첫 줄에 환자 이름, 둘째 줄에 치료코드를 넣습니다. 점심 12:00~13:00은 배정에서 제외합니다. 제외 명단 외의 신규 치료사는 기본 9:00~18:00, 최대 13건을 적용합니다. 관리자 설정 변경은 현재 페이지 세션에만 적용됩니다.

시간 연차는 점심을 제외한 시간으로 계산합니다. 예를 들어 11:30부터 2시간은 14:30까지입니다. 로봇 1시간 치료는 연속된 두 슬롯이 모두 필요하며 점심이나 마감 경계를 넘지 않습니다. 로봇은 1건으로 계산하며 일반치료의 연속 타임 계산에서 제외합니다. 연속 일반치료는 최대 4타임입니다. 특수치료는 지정 시간표로 자격을 확인하며 세션 직전·직후 슬롯은 비워 둡니다. 동일 우선순위·잔여 건수에서는 업로드 후 이름순으로 결정합니다.

자동 배정은 순차적인 우선순위 방식으로 전체 최적해를 보장하지 않습니다. 결과를 확인한 뒤 사용하세요. 수동 드래그 배정과 원본 XLSX 서식 유지·덮어쓰기는 이번 수정 범위에 포함하지 않았습니다. 실제 병원 XLSX가 제공되지 않아 가상 파일로 검증했습니다.

## 개발 및 검증

선택적으로 정적 서버를 실행합니다.

```sh
cd /workspace/replace_schedule
python3 -m http.server 8000 --bind 127.0.0.1
```

이 클라우드 환경에는 Node.js, Playwright, Chromium이 준비되어 있습니다.

```sh
cd /workspace/replace_schedule
node tests/schedule.test.cjs
```

다른 환경에서는 Node.js의 `require('playwright')`가 가능한 설치와 Chromium이 필요합니다. `CHROMIUM_PATH`로 Chromium 실행 경로를 지정할 수 있습니다. 테스트는 임시 HTTP 서버를 자체 실행하고 종료합니다. 가상 스케줄로 배정 규칙을 검사하며 실제 XLSX 업로드와 다운로드된 파일의 내용을 검증합니다.

MM304는 보조 코드로 무시합니다. 쉼표로 함께 적힌 순서와 관계없이 주 처방을 읽습니다. 대체 배정 시 IN302-1은 IN105, MM302-1은 MM105의 30분 일반치료로 변환합니다. 원래 MM302-1 예약의 1시간 점유는 기존 치료사 스케줄에서 유지하며, 대체받는 치료사에게는 변환된 30분 슬롯만 추가합니다. E7774(W)·EZ774(W)는 기존처럼 1시간 로봇 치료로 처리합니다.
